# 📝 مینی پروژه وبلاگ شخصی

## 🚀 اجرای پروژه

برای اجرای پروژه ابتدا دستور زیر را برای اجرای **JSON Server** بزنید:

```bash
npx json-server -w data/db.json --port 8000
```

سپس با دستور زیر پروژه را اجرا کنید:

```bash
npm start
```

> **توجه:** عکس مقالات در پوشه `public` قرار دارد؛ دلیل آن نداشتن Backend است و این روش استاندارد نیست.

---

## ✍️ ساخت مقاله جدید

هنگام ساخت مقاله جدید، در قسمت بارگذاری عکس می‌توانید از آدرس دو عکس زیر برای مقاله جدید استفاده کنید:
‍‍‍‍‍‍‍
`‍‍‍‍‍/photos/greg.jpg`

`/photos/kobu.jpg`



> **توجه:** قبل از زدن دکمه ساخت مقاله و ارسال به JSON Server، باید در فایل کامپوننت `CreateArticle` در پوشه `pages`، آیدی را به‌صورت دستی وارد کنید.

آیدی جدید **نباید با آیدی مقالات قبلی یکسان باشد**.
